# 譜読みタイピング

ブラウザで遊べるピアノの譜読み練習ゲームです。五線に並んだ音符(64音)を、ローマ字で「do re mi fa so ra si」とタイピングして答えます。

## 遊び方
- **Enter** でスタート、**Esc** で中断
- 入力: `do` ド / `re` レ / `mi` ミ / `fa` ファ / `so` ソ / `ra`・`la` ラ / `si`・`shi`・`ti` シ
- 日本語入力(IME)はオフにしてください

## モード
- **ランダム**: 五線内の音がランダムに出題されます
- **蛇**: 2度か3度ずつ上下に連なった音が出題されます
- 音部記号: ト音 / ヘ音 / ミックス(段ごとにランダム)
- 入力ガイド: 画面下のドレミボタンとローマ字対応表の表示/非表示

ノーミスのベストタイムはブラウザに保存されます。

## 構成
ビルド不要の 1 ファイル(`index.html`)。楽譜は SVG で描画しています。GitHub Pages(main ブランチのルート)で公開しています。
